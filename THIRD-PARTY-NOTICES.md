# Visual sources

The guide's palette and selected navigation icons are taken from the European Patients’
Forum's [Patient Empowerment page](https://www.eu-patient.eu/policy/Policy/patient-empowerment/),
as requested, accessed 2026-10-06.

Palette values observed in its stylesheet: blue `#00579a`, dark blue `#004274`,
green `#89d9a3`, dark green `#2b8649`, pale green `#e2f3e4`, pale blue `#d8e5ef`.
Reference stylesheet: `https://www.eu-patient.eu/Static/css/furb.css`.

The SVG files `epf-arrow.svg`, `epf-search.svg`, and `epf-help.svg` under
`dhroxy-template/content/assets/images/` are extracted from
`https://www.eu-patient.eu/Static/css/cssimg/icons-sprite.svg`. Original vector paths
and colours are preserved, with view boxes cropped to the relevant symbol and unused
sprite elements removed. Source group IDs are recorded in each file.

These third-party icons remain attributable to their original owner and are excluded
from this repository's Apache-2.0 license grant. The EPF page states “All rights reserved
to EPF”; this repository does not assert an open license for those icons.

The Dhroxy wordmark is a separate, CSS-styled text mark. The guide's footer credits
the visual source. The guide is independent of EPF and does not imply EPF endorsement.
